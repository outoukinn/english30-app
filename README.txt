English 30｜毎日の仕事英語（無料・広告なし）
===============================================

【内容】
・半年の学習に向けた180日分の予定（26週、週ごとに仕事の場面を反復）
・8表現×26週＝208の仕事英語フレーズ（英語・日本語・読み上げ）
・毎日30分：フレーズ暗記5分、リスニング12分、スピーキング10分、読解3分
・英語音声、会話の文字起こしと日本語訳、発話練習（対応ブラウザのみ音声認識可）
・4メニューの完了記録、学習履歴、学習開始日の設定、JSONバックアップ
・個人情報をサーバーに送る仕組みや外部有料APIは使用していません

【すぐに使う】
このフォルダにある index.html をブラウザで開いてください。
ただし、スマートフォンの「ファイル」アプリ経由で表示した場合は、
学習記録の保存や音声機能が制限される場合があります。
継続利用には以下のWeb公開をおすすめします。

【iPhoneのホーム画面にアプリとして追加する方法】
1. このフォルダ内の5ファイル
   index.html / manifest.webmanifest / service-worker.js /
   icon-192.png / icon-512.png
   を同じ公開フォルダ内に置いて、HTTPSでWeb公開します。
2. 無料のGitHub Pagesを使う例：
   a) GitHubで公開（Public）リポジトリを1つ作成。
   b) この5ファイルをリポジトリ直下にアップロード。
   c) Settings → Pages → Build and deploymentで
      Deploy from a branch / main / (root)を選択して保存。
   d) GitHub Pagesに表示されたHTTPSのURLを開く。
3. iPhoneのSafariでそのURLを開き、共有メニューから
   「ホーム画面に追加」を選択します。
4. 次回以降はホーム画面の English 30 アイコンから開けます。

※GitHub Pages上のアプリ自体は公開URLになりますが、
  学習記録は閲覧者それぞれの端末内に保存されます。
※オフラインで開けるのは、HTTPSで初回読み込みし
  サービスワーカーによる保存が完了した後です。
※英語音声は端末の読み上げ機能を利用します。
  音声認識は端末、ブラウザ、ネット接続、権限の条件で
  利用できないことがあります。
※別端末への記録の自動同期はありません。
  「記録 → 記録を書き出す」でバックアップしてください。
※ChatGPTの毎朝9:00配信とは自動連携していません。
  教材はアプリ内に収録済みで、日付に合わせて切り替わります。
